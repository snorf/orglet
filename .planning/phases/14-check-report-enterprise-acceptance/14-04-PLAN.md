User decision 2 (LOCKED), the flag interplay:
- `--summary` and `--json` suppress the `warning:` stderr lines (names must not leak via stderr in summary mode; JSON carries the full report including names anyway).
- Default mode (no new flags) is byte-identical for the `warning:` lines and their order.
- `--quiet` hides only the human text report. `--json` always prints regardless of `--quiet`.
- `--strict` composes with all of them: exit 1 on any warning, 0 when only informational entries exist.
