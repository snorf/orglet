Bulk 2.0 surface (probe-verified, RESEARCH Pattern 2):
- `POST /services/data/v59.0/jobs/query` JSON `{ operation: "query" | "queryAll", query, contentType: "CSV", lineEnding: "LF" }` -> 200 job info `{ id, state: "JobComplete", ... }` (queries run synchronously); a refused query -> HTTP 400 JSON array `[{ message, errorCode }]` and no job.
- `GET /services/data/v59.0/jobs/query/{id}` -> job info with `state`.
- `GET /services/data/v59.0/jobs/query/{id}/results?maxRecords=2000[&locator=<n>]` -> `text/csv` page, every page repeats the header; headers `sforce-locator` (the string "null" ends paging) and `sforce-numberofrecords`. An empty result body is exactly "\n".
- `GET /services/data/v59.0/sobjects/` -> `{ sobjects: [{ name, replicateable, ... }] }` (globalDescribe sorts with localeCompare: re-sort by code unit). `GET /services/data/v59.0/sobjects/{name}/describe` -> `{ fields: [{ name, type, referenceTo }] }` in schema order.
