<objective>
Give the DML engine a way to run a call on a caller-supplied Postgres transaction, so the Bulk
ingest route (plan 06-04) can commit each 200-record chunk's DML together with its `_orglet`
result rows and counter update in ONE transaction (D-19). This is the only deliberate change
outside `packages/api` in phase 6; it must be backward compatible.

Planning-time decisions (locked; they implement D-19's required properties):
- Shape: a `DmlTransaction { readonly client: PoolClient; readonly events: ChangeEvent[] }` passed as
  `DmlOptions.transaction`, plus an ergonomic `DmlEngine.transaction(fn)` that opens it
  (connect, BEGIN, fn, COMMIT, release) and publishes `tx.events` on the bus after COMMIT.
  Callers that build their own `DmlTransaction` (tests) own BEGIN/COMMIT and publishing.
- In `run()` with an external transaction: no `pool.connect()`, no BEGIN; the engine's work is
  wrapped in `SAVEPOINT dml_run`; success -> `RELEASE SAVEPOINT dml_run`; allOrNone failure and
  thrown errors -> `ROLLBACK TO SAVEPOINT dml_run` then `RELEASE SAVEPOINT dml_run` (thrown errors
  are rethrown); never `client.release()`; events are appended to `tx.events` instead of published.
- Import mode: `run()` still issues `SET LOCAL session_replication_role = replica` when
  `this.importMode`, on either path. On the external path the setting lasts until the caller's
  transaction ends (documented on the option). The existing path is byte-for-byte unchanged.
- The existing per-record `SAVEPOINT rec`, `rollup_batch`, `rollup_parent` savepoints nest under
  `dml_run` unchanged.

Output: engine.ts seam, index.ts export, `packages/engine/src/transaction.test.ts`.

    ```typescript
    /** Run `fn` in one transaction that DML calls join via `{ transaction: tx }`; their change events are published after COMMIT. */
    async transaction<T>(fn: (tx: DmlTransaction) => Promise<T>): Promise<T> {
      const client = await this.pool.connect();
      const tx: DmlTransaction = { client, events: [] };
      let result: T;
      try {
        await client.query("BEGIN");
        result = await fn(tx);
        await client.query("COMMIT");
      } catch (err) {
        await client.query("ROLLBACK").catch(() => undefined);
        throw err;
      } finally {
        client.release();
      }
      await this.bus.publish(tx.events);
      return result;
    }
    ```
