<objective>
The schema side of the formula roll-up backfill (D-10, D-11): `migrate()` stops backfilling roll-ups it cannot compute
(it has no formula engine), reports them, and a new `_orglet.rollup_backfills` marker table lets the engine step (plan 07)
backfill each one exactly once and redo it after a crash.

Purpose: layering `metadata -> schema -> formula -> engine` stays intact; "second `orglet up` is silent" holds on both sides.
The marker table is created by the engine step, not by `migrate()`'s `run()`, so migrate's statement list and the CLI's
change count do not grow (research Mechanism 6, anti-pattern list).
Output: `packages/schema/src/backfills.ts`, migrate change, tests, exports.
</objective>
