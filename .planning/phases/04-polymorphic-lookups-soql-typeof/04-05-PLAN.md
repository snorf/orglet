<objective>
Implement POLY-04: `SELECT TYPEOF <rel> WHEN <Object> THEN <fields> [WHEN ...] [ELSE <fields>] END`
compiles onto the polymorphic joins from plan 04-04 and shapes each row from the matching branch
(D-04), `null` when nothing matches and there is no ELSE (D-18), and the unmodelled-prefix case
takes ELSE (POLY-03 / D-07).

Planner lock (D-07 detail, flagged for review): an unmodelled prefix has no readable row and no
known object, so its ELSE record is `{ attributes: { type: "Name", url: ".../sobjects/Name/<id>" },
Id: <lookup value>, <other ELSE fields>: null }`. `Name` is Salesforce's documented pseudo-object
for an unresolved polymorphic reference (and ELSE lists may only contain Name fields), so this
fabricates no object type. Modelled types never use `Name` (D-02).

Purpose: success criterion 4 (TYPEOF half) and the TYPEOF side of criterion 3.
Output: compiler + shape changes, unit tests, integration tests (Case owners, Task.WhatId).
</objective>

    ```typescript
    function shapeTypeof(t: TypeofShape, row: Row, options: ShapeOptions): Row | null {
      const fk = row[t.fkAlias];
      if (typeof fk !== "string") return null;
      const type = row[t.typeAlias];
      if (typeof type === "string") {
        const branch = t.branches.get(type);
        if (branch) return shapeSObjectRow(branch, row, options);
        return t.else ? shapeSObjectRow(t.else, row, options) : null; // D-18: no matching WHEN, no ELSE -> null
      }
      // Prefix matches no modelled object (D-07): reported once per query by the caller; ELSE can only say what the Name pseudo-object knows.
      options.onUnmodelledPrefix?.(keyPrefixOf(fk));
      if (!t.else) return null;
      const record: Row = { attributes: attributes("Name", fk, options.apiVersion) };
      for (const f of t.else.fields) record[f.name] = f.name === "Id" ? fk : null;
      return record;
    }
    ```
