Contract this plan creates (put in packages/formula/src/compile.ts, export types from packages/formula/src/index.ts):
```typescript
/** Global roots a formula can read; `$System` is the constant OriginDateTime. */
export type GlobalRoot = "$User" | "$Profile" | "$Organization" | "$RecordType" | "$UserRole" | "$Api" | "$Label" | "$CustomMetadata" | "$Setup" | "$System";

/** Fields read on one object: `path` is the relationship path from the formula's record ([] = the record itself). */
export interface ObjectFieldDependency {
  object: string;
  path: string[];
  fields: string[];
}

export interface FormulaDependencies {
  /** Own object first, then parents by path length and path text; field names canonical and sorted. */
  fields: ObjectFieldDependency[];
  /** Sorted, unique. */
  globals: GlobalRoot[];
  /** NOW/TODAY/TIMENOW or an evaluation-time global: the value can change without the record changing. */
  volatile: boolean;
}

export interface CompiledFormula { /* existing fields */ dependencies: FormulaDependencies; }
```
Registry contract (packages/engine/src/formulas.ts):
```typescript
fieldDependencies(obj: SObjectDef, fieldName: string): FormulaDependencies | undefined; // formula fields, case-insensitive
ruleDependencies(obj: SObjectDef, ruleName: string): FormulaDependencies | undefined;   // active validation rules
usesGlobal(root: GlobalRoot): boolean;                                                  // any compiled rule, formula field or default
```
Existing (after 12-02): `resolvePath(schema, objectName, path): { path: string[]; field: FieldDef }` walks typed and plain hops;
`Resolver { schema; objectName; references: Map<string, FieldReference>; usesRecordState: boolean }`;
`rewriteFieldRef` handles `$System` (returns node) and `GLOBAL_OBJECTS` roots `$user/$profile/$organization/$recordtype`;
`rewriteCall` handles PRIORVALUE/ISCHANGED (own-record field refs) and ISNEW, else recurses.
