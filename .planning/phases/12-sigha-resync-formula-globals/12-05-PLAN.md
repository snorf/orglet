<objective>
Resolve `$Label` and `$CustomMetadata` at compile time from the loaded metadata (FORM-04, D-15, D-17), including a warning
channel for formulas that compile but reference a missing custom-metadata record.

Purpose: formulas and validation rules using these globals stop raising `UNSUPPORTED:formula-global`.
Output: two new reference kinds with compile-time values, `CompiledFormula.warnings`, registry and CLI wiring, tests.

Orglet choices recorded in 12-RESEARCH.md (Pattern 3, Q3), restate them in code comments: master label value only (no
translations, CSET-03); `$Label` case-insensitive (getLabel lower-cases); namespaced `$Label.ns.Name` unsupported -> compile
error; record key = DeveloperName, case-insensitive; relationship spanning from a custom metadata type and long text area
fields are documented as not supported in formula fields (Help "Custom Metadata Types and Advanced Formula Fields",
"Custom Metadata Types Limitations") -> compile error; error wording = the generic `Field <ref> does not exist. Check spelling.`.
</objective>
